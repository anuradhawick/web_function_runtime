## What is server-side rendering?

Server-side rendering creates HTML on the server when someone requests a page.
The browser receives the article content without waiting for client-side JavaScript to load it.

## Try it yourself

Refresh this page and watch the server timestamp change. Then view the page source:
the heading and article text are already in the HTML response.

This post is stored in **Markdown** and rendered by a shared Next.js page.
